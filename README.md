# ❄️ Finpolar Frontend
Modern React UI for **Agentic Financial Intelligence**.

### 🚀 Features
- **Real-time Streaming:** Seamless token streaming via Server-Sent Events (SSE).
- **Dynamic Tabs:** Chrome-style navigation for multiple stock analyses.

### 🛠 Tech Stack
- **React 18** (Vite)
- **Tailwind CSS** (Styling)
- **React-Markdown** (Analysis formatting)

### ⚙️ Setup
1. `npm install`
2. `npm run dev`
